# TinyWriter

A distraction-free writing app for macOS. Just open it and start writing.

## Features

- **Clean, minimal interface** — No clutter, just you and your words
- **Rich text formatting** — Bold, italic, and text alignment
- **Automatic saving** — Your work is saved as you type
- **Spell & grammar checking** — Catch mistakes as you write
- **Dark mode** — Easy on the eyes for late-night writing
- **Word & character count** — Track your progress
- **PDF export** — Share your writing with anyone
- **Notes sidebar** — Quickly switch between your documents

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| New Note | ⌘ N |
| Save | ⌘ S |
| Bold | ⌘ B |
| Italic | ⌘ I |
| Increase Font Size | ⌘ + |
| Decrease Font Size | ⌘ - |
| Toggle Sidebar | ⌘ \ |
| Toggle Settings | ⌘ , |
| Toggle Dark Mode | ⌘ ⇧ L |
| Distraction Free Mode | ⌘ ⇧ D |

## Settings

Press **⌘ ,** or open the sidebar and click **Settings** to customize:

- Font family and size
- Line spacing and width
- Dark mode
- Spell and grammar checking
- Word count display
- Notes folder location

## Getting Started

1. Open TinyWriter
2. Choose a folder for your notes (first time only)
3. Start writing

Your notes are saved as RTF files, so you can open them in any word processor.
